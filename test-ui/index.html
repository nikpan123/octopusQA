Jak korzystać z debuggera

  1. Następny krok / F10 wykonuje jeden opisany etap. Jeden etap może zawierać kilka czynności.
  2. ▶ Kontynuuj wykonuje kolejne etapy automatycznie. Ⅱ Pauza zatrzymuje przed następnym etapem.
  3. Punkty podglądu szkół i zamówień wymagają potwierdzenia, także przy automatycznej kontynuacji. Linki otwierają szkoły w osobnych kartach.
  4. ■ Zatrzymaj kończy proces i może przerwać sprzątanie. Aby obejrzeć dane przed usunięciem, poczekaj na punkt „Zatwierdź sprzątanie”.
  5. Po zakończeniu otwórz raport i zapis kroków JSON. Zielony etap potwierdza tylko jego zakres.

Podgląd jest obrazem sesji Playwrighta. Kliknięcia w obraz nie sterują stroną. Czasy debugowania obejmują pauzy na użytkownika.

Test API — krok po kroku

Przygotowanie danych w tle…

Krokami sterujesz tutaj (przycisk lub F10). W otwartej przeglądarce widzisz dokument źródłowy, a po żądaniu — placówkę docelową. To podgląd rzeczywistych skutków API, nie dodatkowe kopiowanie przez UI. Przygotowanie jest automatyczne; ostatni krok zamyka podgląd i uruchamia sprzątanie. Nagłówki autoryzacji nie są pokazywane; większe odpowiedzi są skracane.
